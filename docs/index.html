GameCube & Wii · experimental research

WASM / NOT INTEGRATED

These systems are not playable inside nvd-emu Web yet. RetroArch’s Dolphin core is not a drop-in browser core: Libretro lists it as unavailable for web due to extremely poor performance. A browser port needs a WebAssembly CPU recompiler, graphics backend, audio timing and (for Wii) motion/controller runtime.

Two concrete browser-port candidates exist, but neither is integrated into nvd-emu. Gecko documents a WASM target and native ISO/RVZ support, while its public web demo still asks for IPL/DOL and optional DSP IROM rather than offering a full retail-disc library flow. The experimental Dolphin-derived WASM port has reported poor unique-frame pacing and an unfinished hardware-WebGPU route. Wii support, retail game loading, audio, controls and saves all need reproducible browser testing before either is ready to integrate.

The emulator core files are fetched from EmulatorJS's stable CDN when you launch a game. This means the browser edition needs an internet connection for the core download.

EmulatorJS is GPL-3.0 licensed and the Atari 2600 Stella 2014 core is GPLv2. This site uses the published hosted engine and does not bundle its emulator core assets. Please consult the respective upstream projects for full license terms.

CONTROLS & SAVE DATA
⌨ Keyboard remapping 🎮 Gamepad mapping ↧ Save state ↥ Load state ⚡ Quick save/load 🎮 DualShock analog sticks

Use the emulator toolbar inside the game window to remap keyboard keys and physical gamepad buttons/axes, and use Save State / Load State or Quick Save / Quick Load to preserve progress. PlayStation defaults to PCSX-ReARMed with a DualShock controller profile and HLE BIOS fallback; connect a browser-detected controller and map both sticks in controller settings. Some PS1 games also need analog mode switched on with L1 + R1 + Select. BIOS-free boot and game compatibility vary by title and region. Browser persistence depends on the core and can be cleared by the browser, so export important saves.
