GameCube & Wii · experimental research

WASM / NOT INTEGRATED

These systems are not playable inside nvd-emu Web yet. They require a much heavier PowerPC, graphics, audio and (for Wii) motion/controller runtime; the current EmulatorJS core catalogue does not offer a ready-to-use Dolphin Wii/GameCube core.

A separate open-source project, Gecko, has an early WebAssembly frontend, so a browser-based path is technically possible. Its currently published web page asks for an IPL/DOL file and DSP IROM, and its own project notes say compatibility is still in development. That is not yet a polished, retail-disc Wii/GameCube experience.

PrivacyROM file is not uploaded by this page

The emulator core files are fetched from EmulatorJS's stable CDN when you launch a game. This means the browser edition needs an internet connection for the core download.

EmulatorJS is GPL-3.0 licensed and the Atari 2600 Stella 2014 core is GPLv2. This site uses the published hosted engine and does not bundle its emulator core assets. Please consult the respective upstream projects for full license terms.

Use your own lawfully obtained ROM files. Game ROMs are not included.
