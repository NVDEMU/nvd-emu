Privacy and compatibility

ROM files and the library database stay in your browser profile on this device. NVD-EMU does not upload your selected games to its GitHub repository. EmulatorJS core files are downloaded from its CDN, and console/game artwork is retrieved from external image sources.

Browser storage is tied to this site's origin and browser profile. Using a private window, another browser, clearing website data, or running out of storage can make the library unavailable. Persistent storage is a browser request, not an absolute guarantee.

PS1, Amiga and 3DO games may need BIOS/firmware files that you supply yourself. BIOS files are not bundled. GameCube and Wii remain research targets and are not currently integrated playable systems.

NVD-EMU is a browser frontend, not a ROM download service. Keep backups of save files and use games you are legally entitled to use.
