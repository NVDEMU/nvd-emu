LOCAL CERTIFICATE HELPER

Encode a signing certificate locally

This tool converts a password-protected .p12 certificate file into Base64 text for the GitHub Actions secret APPLE_CERTIFICATE_P12_BASE64.

Private key warning: a .p12 file may contain the private key used to sign macOS releases. Use this page locally, never commit the .p12 or encoded output, and do not share either with anyone. Close this page after copying your secret.
